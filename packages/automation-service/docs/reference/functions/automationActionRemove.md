# Function: automationActionRemove()

> **automationActionRemove**(`httpRequestContext`, `componentName`, `request`): `Promise`\<`INoContentResponse`\>

Remove an automation action.

## Parameters

### httpRequestContext

`IHttpRequestContext`

The request context for the API.

### componentName

`string`

The name of the component to use in the routes.

### request

`IAutomationActionRemoveRequest`

The request payload containing the actionId to remove.

## Returns

`Promise`\<`INoContentResponse`\>

No content response.
